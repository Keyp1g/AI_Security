# Triage labels

| Canonical role | Local status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer evaluation is pending |
| `needs-info` | `needs-info` | More information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready to execute |
| `ready-for-human` | `ready-for-human` | Human implementation is required |
| `wontfix` | `wontfix` | The task will not be actioned |

Skills must use the local status corresponding to the canonical role.
