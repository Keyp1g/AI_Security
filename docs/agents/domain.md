# Domain docs

This repository uses a single domain context.

## Before exploring

- Read root `CONTEXT.md` when it exists.
- Read relevant decisions under `docs/adr/` when they exist.
- If either location is absent, continue without treating the absence as an error.

## Vocabulary

Use terms as defined in `CONTEXT.md`. When a durable new concept is established, add it there rather than introducing competing synonyms.

## Decisions

If a proposed change conflicts with an existing ADR, identify the conflict explicitly before changing the recorded decision.
