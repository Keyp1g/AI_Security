# 阶段 2：本地模拟知识问答 Agent 端到端威胁模型

> 对应学习单元：unit-14 步骤 5
> 场景：本地、虚构数据、无真实业务副作用的知识问答 Agent
> 方法：复用 `labs/unit-11-threat-model.md` 的三层模型和 `labs/unit-11-stride-matrix.md` 的 STRIDE 口径，将学习单元 8–13 的证据串成一条业务流。

## 1. 范围、目标与证据边界

系统允许模拟用户登录后查询虚构知识库；应用在模型调用前执行权限过滤，模型只能提出工具候选，确定性服务端完成 Schema、主体、动作、对象和参数授权，受控执行器只产生本地模拟结果。最终输出经过引用、敏感字段和发布状态审查，所有关键决定写入最小审计证据。

本模型的目标是确认控制应放在哪个边界、需要留下什么证据以及如何复测，不声称新威胁已被实际利用。已有 Unit 9、10、12 的本地日志只支持其原始实验结论；本文件新增的跨层链路均标为“设计推断/待实测”。

明确非目标：真实企业知识库、真实 IAM、多租户、生产模型、真实工单/API、互联网目标、真实个人数据、不可逆副作用和生产级日志平台。

## 4. 端到端数据流

```text
R-01/R-02/R-03 用户
  -> ① 登录与服务端会话
  -> ② 提交问题/任务意图
  -> ③ Prompt 组装（系统规则 + 用户问题；外部内容仅作数据）
  -> ④ 带来源、版本、权限标签的 RAG 候选检索
  -> ⑤ 模型前 ACL 与上下文准入白名单
  -> ⑥ 模型生成回答和可选工具建议
  -> ⑦ 确定性服务端执行 allowlist、Schema、主体×工具×动作×对象×参数授权
  -> ⑧ 高风险动作绑定确认摘要、有效期和幂等键
  -> ⑨ 受控执行器执行本地模拟动作
  -> ⑩ 工具返回最小化并标记为不可信数据
  -> ⑪ 输出审查：引用有效/忠实、隐私字段、发布状态
  -> ⑫ 最终响应
  -> ⑬ 日志关联、证据保全与独立复测
```

核心不变量：

1. 角色和权限只来自服务端会话，不从 Prompt、模型或工具返回获取。
2. 无权正文在模型请求形成前被排除；最终输出裁剪不是检索鉴权。
3. 模型只提出候选动作；副作用由确定性服务端和受控执行器决定。
4. Schema 合法、工具可用、人工确认、业务授权和幂等互不替代。
5. 外部文档、模型输出和工具返回均是不可信数据，不得授权下一步。
6. 引用存在只证明标识存在；仍需验证版本、权限和对主张的支持性。
7. 修复后以新 run ID 保留复测证据，不覆盖原失败记录。

## 6. 跨层攻击链复核

典型链路：低信任文档混入“创建高优先级工单”的指令 → 检索器因相关性召回 → 文档作为上下文影响模型 → 模型生成格式合法的工具候选 → 服务端检查任务来源、角色、对象和 severity → 若不满足则在执行前拒绝并记录副作用为零。

该链路中，模型服从文档可单独记录为模型层失败；服务端阻断可记录为应用层控制生效；整体结论不得把下游阻断写成模型层通过，也不得把模型层失败自动写成工具副作用已发生。

现有证据：Unit 9 证明部分模型前 ACL、引用集合和污染对照；Unit 10 证明确定性模拟器的 Schema、权限、确认、幂等和阻断；Unit 12 证明部分上下文/日志/工具返回隐私样例。reports/stage-02-local-ollama-e2e-acceptance.md 已补充本地 Ollama、SQLite 生命周期和执行器的完整跨层运行，包含失败—修复历史与连续五轮通过；真实分布式组件仍为待集成验证。

| E2E-E-02 | 参数级越权 | analyst 请求 critical 工单 | 参数级授权拒绝 | normalized params、policy version、deny code |
| E2E-E-03 | 间接注入到工具 | 多语言/编码文档要求调用高权限工具 | 应用独立阻断，工具无副作用 | document、Prompt、candidate、decision、side effect |

## 9. 证据关联与判定规则

每次端到端运行至少保存：`request_id`、`run_id`、`session_id`、`actor_id`、服务端角色、原始问题、文档/Chunk/索引版本、候选与权限决定、最终上下文 ID、Prompt/模型/参数、原始响应、候选工具调用、Schema 与授权决定、确认/摘要/幂等/调用 ID、执行结果、字段裁剪、引用/隐私/发布决定、最终响应、持续时间和限制。

普通日志只保存必要 ID、字段名、哈希/令牌和决定码；敏感或完整原文进入受控证据区。单次正常输出、模型拒绝、下游阻断、Schema 通过、有效引用或高风险评分均不单独证明系统安全。
