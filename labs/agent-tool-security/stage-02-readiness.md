## 3. 明确非目标

- 不连接真实工单、文件、搜索、邮件或业务 API。
- 不使用真实身份、客户数据、凭据或持久副作用。
- 不验证真实 LLM 的规划、重复调用或抗 Prompt Injection 能力。
- 不以模型输出的 `confirmed`、role 或 authorized 字段作为授权事实。
- 不把单进程模拟器结论外推到生产 Agent 框架。

## 4. 最小功能与威胁模型

最小控制链已经存在：候选调用 → 工具 allowlist → 服务端身份 → 严格 Schema → 工具权限 → 对象权限 → 参数权限 → 确认 → 幂等 → 受控执行 → 不可信返回隔离 → 最小审计。

覆盖的主要威胁包括：未知工具、角色伪造、对象越权、参数越权、路径绕过、宽松类型、未确认副作用、重复创建、错误泄露和工具返回污染。当前控制链能够证明固定模拟分支在执行前拒绝和副作用为零；真实确认、并发事务、跨服务审计和模型参与仍待验证。
