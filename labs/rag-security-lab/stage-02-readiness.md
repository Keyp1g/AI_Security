## 3. 明确非目标

- 不连接真实企业知识库、生产向量数据库或第三方数据源。
- 不验证真实租户 IAM、动态组织结构或生产缓存。
- 不执行文档中的控制样式文本，也不连接真实工具。
- 不以单次输出、相似度或有效引用证明事实正确和系统安全。
- 不在本步骤部署新服务或下载面向公网的实验系统。

## 4. 最小功能与威胁模型

最小功能链已经存在：批准目录读取 → 元数据校验 → 稳定切分 → 离线相似度 → 模型前权限过滤 → TopK → 来源/信任传播 → 本地生成 → 引用白名单 → 输出决定 → JSONL。

主要威胁覆盖：未批准文档入库、权限标签丢失、跨范围召回、低信任内容污染、文档指令劫持、引用伪造/过期、撤销不同步和日志保存正文。当前最强证据集中在模型前 ACL、污染对照、引用集合检查和不可信上下文复核；生命周期删除、真实向量库和最终 UI 门禁仍是待验证项。

## 8. Readiness 结论

作品 2 的需求、虚构数据、最小原型、检索时鉴权、引用和污染测试已经存在且可验收；本地 SQLite 生命周期夹具进一步完成撤销、Chunk/索引/缓存/引用失效和干净恢复实测。最终发布门禁、真实向量库、分布式缓存和动态权限仍有缺口。当前判定为 **本地实验能力可验收，真实组件集成仍不完整**，不得描述为生产级 RAG 安全系统。
