# 学习单元 11：企业内部知识助手威胁模型

> 状态：离线威胁建模完成；未运行的行为测试均保持“待实测”。
> 场景：本地虚构企业知识问答助手，不连接真实客户、身份系统、文档或业务 API。

## 1. 业务目标与非目标

业务目标：为不同角色提供与其权限相符的课程资料和内部模拟文档问答；允许受控调用模拟搜索与模拟工单工具；保存足以复测的最小审计证据。

非目标：

- 不执行真实退款、订单、邮件、系统管理或互联网操作。
- 不接入真实员工、客户、密钥、域名或生产知识库。
- 不以模型拒答作为身份、对象权限或副作用控制。
- 不对外部服务进行扫描、越权尝试或压力测试。

## 2. 角色与允许操作

| 角色 | 身份来源 | 允许操作 | 禁止操作 |
|---|---|---|---|
| visitor | 服务端虚构会话 | 查询公开课程资料；查看公开引用 | 检索内部文档；创建工单；维护索引；修改策略 |
| analyst | 服务端虚构会话 | 查询公开及本租户内部文档；调用模拟搜索；创建 low/triage 工单 | 跨租户检索；high 工单；修改索引、Prompt 或授权策略 |
| admin | 服务端虚构会话 + 模拟审批 | 维护文档准入、索引版本和策略；查看脱敏审计元数据 | 绕过审批；读取不必要原文；将应用端口公开 |
| service | 工作负载身份 | 按最小权限访问模型、索引、工具和审计接口 | 交互登录；修改自身角色；访问未注册工具 |

## 4. 入口

| ID | 入口 | 输入 | 默认信任 | 首要控制 |
|---|---|---|---|---|
| EP-01 | Web/API 聊天入口 | 消息、附件、会话引用 | 不可信 | 身份绑定、大小限制、来源标记 |
| EP-02 | 文档接入入口 | 文档、来源、ACL 请求 | 不可信 | 准入、服务端元数据、哈希和版本 |
| EP-03 | 检索入口 | 查询、主体范围 | 查询不可信，范围须可信 | 服务端 ACL 预过滤 |
| EP-04 | 模型网关 | Prompt、参数、租户 | 混合信任 | 路由策略、最小上下文、限额 |
| EP-05 | 工具网关 | 候选工具与参数 | 未授权候选动作 | allowlist、Schema、对象授权、确认、幂等 |
| EP-06 | 工具结果入口 | 结构化数据和正文 | 不可信数据 | 返回 Schema、字段白名单、来源标签 |
| EP-07 | 输出渲染入口 | 模型回答、引用 | 不可信输出 | 解析、编码、敏感信息和引用审查 |
| EP-08 | 管理控制面 | 模板、ACL、索引、策略变更 | 高权限输入 | 强认证、审批、版本和审计 |

## 5. 信任边界

| ID | 边界 | 主要风险 | 必要控制 | 证据 |
|---|---|---|---|---|
| TB-01 | 外部用户/客户端 -> 身份与会话服务 | 身份/角色伪造、会话重放 | 服务端身份、会话绑定、限流 | actor/session、认证结果、request ID |
| TB-02 | 用户/外部内容 -> Prompt 与 Agent 上下文 | 指令和数据混淆、记忆污染 | 来源标签、上下文分区、最小上下文 | template/context IDs、来源、哈希 |
| TB-03 | 文档接入 -> 受控语料与索引 | 文档污染、伪造 ACL、旧版本残留 | 准入、服务端元数据、版本、撤销 | document/chunk IDs、ACL、index version |
| TB-04 | 应用编排 -> 模型平台 | 跨租户路由、敏感上下文、资源滥用 | 服务端租户绑定、密钥托管、预算 | model/deployment、tenant、parameters |
| TB-05 | 模型/Agent -> 工具执行域 | 模型输出被当授权、对象/参数越权 | allowlist、Schema、再授权、确认、幂等 | tool、arguments hash、decision、result ID |
| TB-06 | 工具/模型输出 -> 用户和下游 | 泄露、活动内容、错误引用、过度依赖 | 结构校验、编码、脱敏、引用审查 | output decision、rule version、response ID |
| TB-07 | 各组件 -> 日志与证据区 | 日志注入、过度留存、证据缺失 | 字段白名单、证据分区、防篡改 | request ID、event type、evidence ref |
| TB-08 | 管理员 -> 管理控制面 | 配置篡改、权限滥用、抵赖 | 强认证、审批、双人复核、回滚 | actor、approval、before/after hash |

## 6. 关键数据流

```text
visitor/analyst/admin
 -> 身份与会话
 -> 对话编排与 Prompt 组装
 -> ACL 过滤后的 RAG 检索
 -> 模型网关与模型
 -> 输出审查
 -> 用户界面

模型候选工具调用
 -> allowlist/Schema
 -> 主体×动作×对象×参数授权
 -> 确认与幂等
 -> 模拟工具
 -> 不可信工具结果隔离
 -> 输出审查或下一轮候选规划
```

## 7. 责任与安全不变量

1. 主体、角色和租户只从服务端会话取得。
2. 文档相关性不代表访问权限或来源可信度。
3. 模型输出和合法 JSON 都是候选信息，不是授权决定。
4. 无权正文在进入模型上下文前阻断。
5. 高影响副作用需要绑定主体和精确参数的可信确认。
6. 普通日志不默认保存完整 Prompt、文档、工具返回或密钥。
7. 所有管理变更可关联操作者、审批、前后版本和回滚。
