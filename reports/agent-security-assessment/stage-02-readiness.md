## 3. 明确非目标

- 当前不声称对真实 Agent 产品、真实客户系统或生产模型完成评估。
- 不把模板存在、用例数量、平均分或最高分当成安全结论。
- 不把待实测风险、已阻断控制或模拟器结果登记为已确认生产漏洞。
- 不覆盖或删除旧失败证据，修复后必须创建独立复测记录。
- 不在公开报告中保存真实秘密、个人信息或无必要的精确活动时间。

## 4. 最小功能与威胁模型

最小报告能力已经定义：文档控制 → 摘要 → 授权/范围 → 环境基线 → 架构/资产/边界 → 方法/用例/评分 → 发现清单 → 单项事实/推断/限制 → 根因/修复/复测 → 未验证项 → 证据附录。

报告输入已覆盖 Prompt Injection、RAG 污染、Agent 工具授权、上下文/日志/工具隐私和测试证据治理。步骤 5 的端到端威胁模型将作为最终报告的架构和 STRIDE 依据。

## 6. 安全验收
