## 2. 默认实验环境设计

| 项目 | 要求 |
|---|---|
| 环境名称 | Unit 15 Local HTTP Fixture |
| 运行位置 | 本机 Windows；仓库 labs/web-security 下的课程夹具 |
| 监听地址 | 仅 127.0.0.1，不绑定 0.0.0.0、局域网 IP 或公网接口 |
| 端口 | 启动时选择未占用的高位端口并写入环境记录，不长期假定固定端口 |
| 技术依赖 | Python 标准库优先，不要求 Docker、数据库或外部包 |
| 数据 | 全部为虚构账号、虚构会话、虚构搜索内容和可重置内存状态 |
| 浏览器 | Edge、Chrome 或 Firefox 的独立临时 Profile，只打开本地夹具标签页 |
| 请求工具 | 浏览器 Network 面板和 curl，不使用自动扫描器 |
| 外部网络 | 实验服务不得主动访问互联网，浏览器不得混入真实业务标签页 |
| 副作用 | 默认只读；表单仅写可清空的内存夹具，不发送邮件、不写真实文件、不调用外部 API |

建议的最小本地功能：GET / 首页；POST /login 虚构登录；GET /session 会话状态；GET /search 无害搜索与分页；POST /feedback 可重置虚构表单；GET /api/items 虚构 JSON；GET /redirect-demo 本地重定向；GET /error-demo 受控错误；POST /reset 清空内存状态。该清单是环境需求，不表示本步骤已经启动或实测这些路由。

## 3. 资产与授权记录

Unit 15 开始前必须在 labs/web-security/unit-15-environment-record.md 保存：环境 ID、名称与版本、127.0.0.1 实际端口、授权来源、允许的虚构账号、synthetic_only 数据分类、允许/禁止动作、日志位置、重置方式、网络边界和停止条件。

授权来源固定为本地自建课程夹具；执行人拥有本机和仓库控制权。若改用明确授权练习平台，必须额外保存平台 URL、授权说明、账号范围、允许时间、速率、数据类型和停止条件，授权不得来自模型输出或输入文本中的单方声明。

## 4. 浏览器隔离与请求记录

### 4.1 浏览器隔离

- 使用独立临时 Profile，不复用日常浏览器登录状态、Cookie、扩展和同步账号。
- 启动前关闭该 Profile 的其他标签页，只访问 127.0.0.1 的课程端口。
- Network 记录前清空旧请求；实验结束后关闭 Profile 并删除临时运行数据。
- Profile 真实路径不写入公开成果；若独立 Profile 创建失败，使用 Guest/隐私窗口并记录限制。

### 4.2 请求证据分层

| 证据层 | 保存内容 | 推荐位置 | 发布规则 |
|---|---|---|---|
| 普通学习记录 | Request ID、动作、方法、路径、状态码、字段名、认证存在性和安全观察 | labs/web-security/unit-15-http-request-inventory.md | 可进入成果，不含完整敏感值 |
| 脱敏文本证据 | 头名称、遮盖值、JSON 字段结构和响应摘要 | labs/web-security/evidence-sanitized/ | 审查后使用 |
| 原始 HAR/Network 导出 | 可能含 Cookie、Token、路径参数和响应正文 | labs/web-security/evidence-private/ | 本地受控，不默认发布 |
| 服务端运行日志 | request_id、方法、模板化路径、状态码、耗时、决定码 | labs/web-security/runtime/logs/ | 不记录密码、Cookie、Authorization 或正文原值 |

HAR 即使来自本地虚构环境，也必须先检查 Cookie、Authorization、Set-Cookie、CSRF、password、email、phone 和 session 字段后再决定是否保留。

## 5. 脱敏规则

| 数据 | 普通记录允许内容 | 禁止保存内容 |
|---|---|---|
| Cookie / Set-Cookie | 字段存在性、Cookie 名、Secure/HttpOnly/SameSite 属性 | 完整 Cookie 值 |
| Authorization | 类型、是否存在、遮盖后的前后缀或长度 | 完整 Token |
| CSRF Token | 字段名、是否存在、长度 | 完整值 |
| password | 字段名、是否提交、长度区间 | 明文或可恢复值 |
| session ID | 本地 Request ID 映射或不可逆指纹 | 原始会话标识 |
| email / phone | 合成标识或固定令牌 | 真实个人信息 |
| 查询与表单正文 | 虚构关键词、字段名和允许的单变量变化 | 真实业务内容、秘密或个人数据 |

需要跨请求关联虚构会话时，使用课程生成的合成 ID 或受控 HMAC/令牌。

## 6. 备份、重置和清理

1. 服务状态默认只存在内存，每次启动从固定虚构夹具重建。
2. 开始前保存夹具脚本哈希或版本，避免代码变化后继续沿用旧证据。
3. 每组参数变化结束后恢复基线，记录 reset 事件和新 request_id。
4. 进程异常时先保存脱敏日志，再停止进程；重新启动视为新运行批次。
5. 原始 HAR 只在脱敏校验前临时保留，不进入公开索引。
6. 实验完成后确认没有遗留监听端口、后台服务、临时 Profile 或明文令牌文件。

## 7. 网络边界与停止条件

网络边界：服务仅监听 127.0.0.1；不配置端口转发、反向代理、局域网共享、隧道或公网暴露；夹具不实现 URL 抓取、Shell、文件上传、插件安装或外部 API；curl 和浏览器只访问实际记录的课程地址。

立即停止条件：监听地址不是回环；出现真实 Cookie、Token、密码、个人信息或内部 URL；Network 混入日常业务流量；请求访问外部域名或非课程服务；参数变化触发不可恢复写入或账号状态变化；授权、账号归属或重置能力不清楚；证据无法区分本地夹具、离线样本和真实请求。

## 8. 允许与禁止清单

### 8.1 允许

- 观察本地或明确授权练习环境的请求。
- 使用 curl 重放自己刚生成的本地无害请求。
- 修改搜索词、page、limit、sort 和虚构非持久化表单字段，一次只改一个变量。
- 观察状态码、Content-Type、重定向、Cookie 属性、错误结构、request_id 和课程日志。
- 使用虚构账号、虚构会话和虚构数据。
- 停止并重启本地夹具，验证重置和证据批次边界。

### 8.2 禁止

- 扫描公网、陌生域名、局域网设备或非课程端口。
- 抓取日常账号、真实 AI 服务、生产 API 或内部业务系统请求。
- 使用真实账号、客户数据、真实 Cookie、Token、API Key、邮箱或手机号。
- 修改 user_id、role、owner、resource_id、认证字段或对象权限来尝试越权。
- 测试真实 IDOR、XSS、SSRF、RCE、文件上传、路径遍历、命令执行或认证绕过。
- 运行目录爆破、漏洞扫描、口令猜测、高并发压测或破坏性请求。
- 把前端显示、HTTP 200、模型回答或用户自称已批准当作服务端授权证据。
