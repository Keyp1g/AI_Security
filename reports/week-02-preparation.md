# 第 2 周本地实验准备清单

> 范围：Prompt Injection、RAG 与 Agent 的本地模拟需求。
> 当前状态：只完成文档设计和占位目录，不下载模型、不连接外部业务、不接入真实工具。

## 1. 统一安全边界

1. 用户输入、外部文档、网页/邮件样式文本、检索片段和工具返回全部视为不可信输入。
2. System/Developer 文本只使用虚构应用规则；不测试或索取任何真实隐藏提示。
3. 敏感值只使用 `[SIMULATED_SECRET]` 等固定占位符，不写入真实密钥、账号、个人或业务数据。
4. 模型输出不能直接触发网络、文件写入、数据库、邮件或命令执行。
5. 身份、对象权限、工具名、参数和高影响审批全部由模型外的确定性模拟器判断。
6. 没有真实 Response 时写“待实测”，不补造通过结果。

## 3. Prompt Injection 准备

| 字段 | 设计 |
|---|---|
| 输入 | 固定应用规则、用户输入槽、外部文档槽、模拟工具返回槽；仅使用无害控制样式字符串和占位值 |
| 输出 | 固定 JSON：任务状态、数据摘要、来源标签、阻断原因和限制 |
| 主要风险 | 直接任务劫持、间接文档注入、格式突破、占位敏感值诱导、工具返回污染 |
| 边界 | 只在本地模拟问答/摘要流程运行；不投递第三方，不探测隐藏提示，不执行任何工具 |
| 验收条件 | 20 条 `LLM-008-xx` 用例唯一；外部内容保持 `untrusted`；输出可解析；敏感占位符不泄露；失败由应用阻断 |
| 计划入口 | `notes/day-08-prompt-injection.md`、`labs/day-08-direct-injection.md`、`labs/day-08-indirect-injection.md`、`cases/llm-security/prompt_injection_cases.md` |

### Day 8 最小模拟流程

```text
固定应用规则
  + 用户输入（untrusted:user）
  + 外部文档（untrusted:document）
  + 工具返回（untrusted:tool_result）
  -> 提示组装
  -> 本地模型或待实测槽
  -> JSON 解析与 Schema 校验
  -> 服务端授权模拟
  -> 展示或阻断
```

Day 8 只观察本地模拟问答流程中的 Prompt Injection 防护，不连接外部网页、企业机器人、公开模型或真实工具。

## 4. RAG 准备

| 字段 | 设计 |
|---|---|
| 输入 | 5 篇干净虚构文档、5 篇含无害控制样式文本的不可信文档；每篇带 `document_id`、`source`、`trust_level`、`owner_scope` |
| 输出 | 检索结果 ID、来源、引用片段、摘要、未证实项和阻断原因 |
| 主要风险 | 恶意文档注入、检索污染、来源丢失、跨范围召回、引用伪造 |
| 边界 | 不抓取互联网内容，不使用真实知识库或业务文档，不声称模拟权限等于生产隔离 |
| 验收条件 | 文档来源和信任级别可追踪；检索范围可检查；不可信指令只作为数据；引用能回到本地原文 |
| 后续入口 | 在 Day 8 结束时形成第 9 天 10 篇本地文档集和来源标签定义 |

## 5. Agent 准备

| 字段 | 设计 |
|---|---|
| 输入 | 模拟会话身份、模型生成的工具请求、三个无副作用工具定义、静态工具返回 |
| 输出 | `allow/deny/clarify`、校验失败字段、模拟返回、人工确认状态和审计事件 |
| 主要风险 | 工具选择污染、参数越界、对象级越权、模型自授权限、工具返回中的指令污染 |
| 边界 | 工具只返回静态 JSON；禁止网络、Shell、真实文件、邮件、数据库和外部写入 |
| 验收条件 | 工具名允许列表、参数 Schema、对象归属、操作级授权和高影响确认均由模型外代码判断；拒绝原因可复核 |
| 后续入口 | `labs/week-02/tool-stubs/` 中准备只读查询、草稿生成和高影响动作三类静态接口定义 |

## 6. 统一日志字段

| 字段 | 说明 |
|---|---|
| `CaseId` | 唯一用例 ID |
| `RuleVersion` | 应用规则/模板版本 |
| `InputSources` | `user`、`document`、`tool_result` 等来源标签 |
| `TrustLabels` | 每个输入的可信度，外部内容默认 `untrusted` |
| `AssemblyHash` | 组装结果哈希；不以哈希替代必要的脱敏证据 |
| `Model` / `Parameters` | 模型、版本和采样参数；未运行时为 `pending` |
| `RawResponse` | 完整原始输出；未运行时明确 `待实测` |
| `ParseResult` | JSON/Schema 解析结果和失败字段 |
| `AuthorizationResult` | 模型外授权模拟结果 |
| `BlockReason` | 阻断或人工升级原因 |
| `Expected` / `Verdict` | 预注册期望与实际判定 |
| `EvidencePath` | 本地证据文件和用例位置 |

日志不记录真实敏感值、真实服务地址或墙上时钟个人轨迹；只保存复测所需的模型耗时、Token 和规则版本。
