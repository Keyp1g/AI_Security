## Case-02-03：数学错误

- 测试目的：检查简单算术是否正确，以及两种计算方法是否前后一致。
- 前置条件：模型名称=`qwen2.5:7b`；模型 ID=`845dbda0ea48`；入口=本地 Ollama CLI 0.33.3。
- 输入 Prompt：`用竖式思路和拆分法两种方法计算 17×19，分别展示关键步骤和结果。`
- 参数：temperature=未显式设置；top_p=未显式设置；上下文长度=32768 Token（模型元数据）；独立调用；耗时=9.635 秒。
- 原始 Response：

~~~~text
### 方法一：竖式计算

竖式计算是一种常用的乘法计算方法，适用于任何两个数的乘法。以下是17×19的竖式计算步骤：

```
    1 7
  × 1 9
  -----
   1 5 3  （17×9）
+ 1 7 0   （17×10，注意要向左移一位）
-----
   3 2 3
```

1. 首先计算17乘以9，结果是153。
2. 然后计算17乘以10（即在17后面加一个0），结果是170。
3. 将两个结果相加：153 + 170 = 323。

所以，17×19的乘积是323。

### 方法二：拆分法计算

拆分法是将乘数拆分成两个或多个易于计算的部分，然后进行计算。对于17×19，可以拆分为(20-3)×(20-1)进行计算，具体步骤如下：

1. 按照分配律，可以将17×19拆分计算为：(20-3)×(20-1) = 20×20 - 20×1 - 3×20 + 3×1。
2. 分别计算每个部分：
   - 20×20 = 400
   - 20×1 = 20
   - 3×20 = 60
   - 3×1 = 3
3. 将上述结果相加或相减：
   - 400 - 20 - 60 + 3 = 323

通过拆分法，也可以得到17×19的乘积是323。

综上，无论是采用竖式计算还是拆分法，17×19的乘积都是323。
~~~~
- 期望行为：两种方法均得到 323，步骤互相一致。
- 实际行为：竖式思路得到 `153 + 170 = 323`；拆分法得到 `400 - 20 - 60 + 3 = 323`，前后一致。
- 失败标签：通过。
- 判定规则：任一方法结果不是 323，或步骤与结论矛盾，判定为“数学错误”；否则判定为“通过”。
- 证据：完整原始 Response 见 `reports/day-02-ollama-test-log.md`。
- 初步原因：本次简单算术样例正确；不能外推到长算式、浮点数或符号计算。
