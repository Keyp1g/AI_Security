- 详细 Prompt、预注册期望和评分规则：`labs/day-05-template-evaluation.md`。
- 判定：当前结果以 `v0.2` 为准，同时保留 `v0.1` 作为修复前基线；“部分通过”与“不通过”不会因格式可解析而被改写成通过。
