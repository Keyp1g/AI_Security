# LLM 风险初表

> 阶段：Day 2
> 边界：本表来自教材学习与本地 `qwen2.5:7b` 行为实验，不代表已经完成模型内部安全审计。

| 风险 | 触发条件 | 影响 | 可观测证据 | 可验证的初步控制 |
|---|---|---|---|---|
| 幻觉 | 问题缺少可靠上下文，模型倾向补全 | 错误事实、决策或引用 | 虚构事实、无法核验的来源 | 加入不存在对象与来源核验用例；要求不确定性声明并人工复核 |
| 输出不稳定 | 随机采样、参数或上下文变化 | 回归结果波动、自动化判断困难 | 同一 Prompt 五次出现 3 种输出 | 记录模型和采样参数；固定 seed；重复测试并统计通过率 |
| 上下文信息丢失 | 长文本、关键信息位置变化、重复内容干扰 | 遗漏安全约束或关键证据 | 短上下文返回 `BLUE-17`，2050 Token 长上下文返回 `None` | 分层改变长度和位置；在执行前重新校验关键约束 |
| 指令误解 | 目标、格式或边界不明确 | 输出不可用、错误执行 | 模糊审计请求先生成通用清单，清晰指令逐项询问前置条件 | 使用结构化输入；校验字段、格式和任务边界 |
| 过度拒答 | 安全策略范围过宽、语义误判 | 正常业务不可用 | 低风险定义请求被无理由拒绝 | 建立允许集样例；记录拒答原因并人工抽样 |
| 不足拒答 | 有害意图被改写或安全策略被绕过 | 输出危险操作指导 | 未授权攻击请求未拒绝或仍给出关键步骤 | 建立拒答用例；对高风险请求做分类、授权校验和沙箱隔离 |
| 隐私泄露 | Prompt、日志或检索内容含敏感数据 | 个人或业务数据暴露 | 请求或响应出现预置的敏感标记 | 输入脱敏；最小化日志；限制访问并检测标记泄露 |
| 偏见 | 训练数据、测试样本或上下文含刻板模式 | 不公平判断与合规风险 | 对等输入因群体属性得到不同结论 | 构造配对样本；比较差异并对高影响决策人工复核 |

## 后续验证

- 为 JSON、行数、拒答关键内容和事实来源建立自动判定规则。
