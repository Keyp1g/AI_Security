# AI 安全学习与实践

## 公开边界

公开成果必须满足“计划要求 → 实际产物 → 验证证据”映射。实验失败会如实保留，不能被改写成安全结论；尚未覆盖真实平台的范围继续标为待验证。模型文件、教材副本、编辑器日志、服务器运行手册、个人草稿和后续学习单元不进入公开范围。

所有测试使用本地环境、合成数据、模拟工具或明确授权的实验环境，不提交真实密钥、个人信息或业务数据。
