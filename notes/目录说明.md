目录说明

项目的 canonical 身份是 `unit-NN`（学习单元）和 `stage-NN`（阶段）。它们表示进度与课程结构，不表示自然日或自然周。完整规则见 [`../docs/project-structure.md`](../docs/project-structure.md)。

| 目录      | 用途                     | 示例                    |
| --------- | ------------------------ | ----------------------- |
| `notes`   | 概念、阅读笔记、机制说明 | `unit-02-llm-basics.md` |
| `labs`    | 可运行实验、夹具和实验说明 | `unit-08-direct-injection.md` |
| `cases`   | 结构化安全测试用例和作品库 | `unit-12-privacy-leakage.md` |
| `reports` | 原始运行证据、学习单元复盘和阶段总结 | `unit-12-review.md` |
| `docs`    | 领域上下文、成果注册表、结构说明和 ADR | `learning-units.md` |
| `tools`   | 脚本、评测器和辅助工具 | `ai-security-evaluator` |
