## 二、资料与安全边界

阅读教材中的 Agent、工具调用、不安全插件设计、过度代理内容。今日工具均为模拟实现或文档接口：`search_simulated`、`read_allowed_file`、`create_mock_ticket`。不得连接网络、读取真实文件、创建真实工单、执行命令、调用支付/账户/邮件等高影响服务。模型只能提出调用建议；工具服务端必须独立验证身份、权限和参数。

### 09:00-10:00：绘制 Tool Calling 流程

#### 具体动作

绘制：`用户请求 -> 意图/权限预检 -> 模型选择工具 -> schema 参数生成 -> 服务端验证 -> 风险确认 -> 模拟执行 -> 观察结果 -> 输出审查 -> 审计日志`。标注“模型不能直接执行”“工具响应不可作为新指令”“敏感或有副作用动作须确认”的位置。为每步写日志字段。

#### 产出与验收

- [x] 11 个节点和 5 个阻断点。
- [x] 有参数 schema、服务端授权和人工确认。
- [x] 说明为什么仅在 Prompt 中写规则不充分。

### 10:00-11:00：定义三个模拟工具

#### 具体动作

在 `labs/agent-tool-security/day-10-tool-specs.md` 定义三个工具的 JSON schema、允许角色、允许范围、禁止参数、返回字段、错误码、审计字段和副作用：

| 工具 | 允许动作 | 禁止动作 | 副作用 |
|---|---|---|---|
| `search_simulated` | 查询本地虚构索引 | URL、网络、命令参数 | 无 |
| `read_allowed_file` | 读取 allowlist 中的虚构文件 ID | 路径遍历、绝对路径、敏感目录 | 无 |
| `create_mock_ticket` | 在内存/文档中创建模拟工单 | 真实外部提交、任意指派、敏感内容 | 仅模拟记录 |

#### 产出与验收

- [x] 三个工具都有可机器校验的参数范围。
- [x] 错误返回不泄露内部细节。
- [x] 所有副作用均为模拟且可撤销。
