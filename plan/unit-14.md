## 二、验收与安全边界

本阶段验收范围为学习单元 8-13：Prompt Injection、RAG、Agent 工具调用、训练/上下文/日志/工具返回泄露、AI 红队方法与报告。只能审计本地或明确授权模拟环境的设计和证据；不因本阶段计划出现 Web、IDOR、XSS、SSRF、RCE 等词就提前对真实目标进行测试。

验收状态使用以下定义：

| 状态 | 含义 | 是否计入已验证通过率 |
|---|---|---|
| 通过 | 已在授权环境观察到满足期望的控制行为，证据完整 | 是 |
| 失败 | 已在授权环境观察到偏离期望的行为，证据完整 | 是，且应进入修复/复测 |
| 待实测 | 用例和期望已设计，但没有实际执行证据 | 否 |
| 阻断 | 防护按预期阻止动作，仍保留请求和日志证据 | 是，但需说明阻断点 |
| 未授权/不执行 | 不具备授权、环境或数据前置条件 | 否 |
